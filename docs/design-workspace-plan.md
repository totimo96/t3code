# Design Workspace Implementation Plan

## First Slice

1. Add persisted Thread Workspace Kind and a sidebar Workspace Switch.
2. Add a Design Route and Design Thread empty state using the existing composer.
3. Add Design Brief events, persistence, projections, and a visible brief panel.
4. Add Design Artifact events, persistence, projections, and a sandboxed iframe Design Canvas for the current artifact.
5. Add Create Design Artifact through a manual UI action or minimal structured agent command.
6. Add Click Targeting and Box Targeting with Target Prompt Context.
7. Generate three Design Variants by default and support Accept Design Variant.
8. Add Apply Design Artifact as a Coding Handoff.

## Deferred

- Freehand Targeting.
- Manual Style Controls for color, typography, spacing, and radius.
- Direct project-file application outside the Coding Handoff flow.
